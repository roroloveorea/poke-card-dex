# Artwork sources

PokeCardDex records the source of artwork bundled with the project. Provider-backed card and set images remain remote catalog data and are not copied into the repository.

| Asset | Source and usage |
| --- | --- |
| `public/artwork/catalog-hero-pikachu.webp` | Supplied by the project owner on 2026-08-24 for use as the decorative Home hero image. |

The interface identifies PokeCardDex as an unofficial collector reference. Pokémon card imagery shown in catalog results is supplied at runtime by the configured catalog providers and retains provider attribution in the associated card and price metadata.
